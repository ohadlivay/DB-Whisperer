# DBWhisperer Evaluation V2 (historical)

Evaluation V2 is a preserved historical experiment. It is intentionally not
runnable after removal of join-path ambiguity from DB Whisperer; its runner
fails immediately before API-key checks, directories, status files, monitoring,
ETL, or model activity.

The V2 cases, scoring, reports, and implementation remain available only for
historical comparison. They describe the former five-arm design, including the
retired Join Only arm, and must not be used to create or publish new results.

Use `benchmark_v3` for current suite validation and the supported evaluation
workflow.
